README — Doctor & Secretary Views

👨‍⚕️ Doctor View

Admin Dashboard

Overview includes:

  • Summary of Schedule
  • Patient Count of the Week (Bar Graph by Walk-in or Appointment)
  • Queue Status
  • Quick Access Buttons

List of Patient Records

  • Queue List
  • Doctor Schedule
    • Availability of the Doctor
    • View and Edit Schedule

Patient History Record

  • Editable, Updatable, Addable
  • Filter by Date or Alphabet (A–Z)

Current Queuing

Queue Board (Right Side):

  • Sorted A–Z
  • Patient Name
  • Company Affiliation (if applicable)
  • Appointment Type (Booked / Walk-in)
  • Consultation Description

Current Patient Info (Left Side):

  • Name
  • Patient Data

Audit Logs

  • Track of Consultation Schedules
  • Track of Actions
  • Filter by: Username, User ID, Date

Settings

  • Account Info
  • Add a Person (e.g., Secretary)
    • Name
    • Role
    • Restrictions
  • Edit Information
  • Change Password

👩‍💼 Secretary View

Admin Dashboard

Overview includes:

  • Summary of Schedule
  • Patient Count of the Week (Bar Graph by Walk-in or Appointment)
  • Queue Status
  • Quick Access Buttons

List of Patient Records

  • Queue List
  • Doctor Schedule
    • Availability of the Doctor
    • View Schedule
    • Edit and Update (Access granted by the Doctor)

Patient History Record

  • Editable, Updatable, Addable (Access granted by the Doctor)
  • Limited Record View
    • Name
    • Last Visit Date
  • Drag and Drop to Queue Board

    Once information is dropped, the system automatically updates the patient’s history to reflect the visit date.

  • Filter by Date or Alphabet (A–Z)

Current Queuing

Queue Board (Right Side):

  • Sorted A–Z
  • Patient Name
  • Company Affiliation (if applicable)
  • Appointment Type (Booked / Walk-in)
  • Consultation Description

Current Patient Info (Left Side):

  • Name
  • Patient Data

Appointment / Consultation Logs

  • Track Consultation Schedules
  • Track Actions
  • Filter by: Username, User ID, Date

Settings

  • Account Info
  • Add a Person (e.g., Secretary)
    • Name
    • Role
    • Restrictions
  • Edit Information
  • Change Password

About

This README contains the Doctor and Secretary view specifications for the Patient Management System. Use this as documentation for UI implementation and role-based access control.

Notes

  • Use role-based permissions to restrict secretary access to sensitive records.
  • Queue Board should support drag-and-drop for appointment handling.
  • Graphs and charts are placeholders for integration with a charting library (e.g., Chart.js).
